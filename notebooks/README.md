# Cuadernos

Espacio para exploración y validación con Jupyter (extensión `ms-toolsai.jupyter`).
Ideas para empezar, una vez procesado el mes de prueba:

- Abrir `data/processed/monthly/precipitation/precipitation_2015-07.nc` con `xarray` y
  comparar la media nacional con un reporte publicado de ese mes.

Usa el mismo entorno del backend (`backend/.venv`). No guardes credenciales ni salidas
pesadas en los cuadernos.
